### 🧵 Post 2: Branchless ZK Proof Optimization
> How do we check credentials without revealing *which* voter voted? 🤫
> 
> We implement a depth-3 Merkle Tree and run a branchless ZK path verification on-chain. By avoiding conditional execution paths, we enforce 100% zero-knowledge unlinkability. The compiler is green! 🚀 
>
